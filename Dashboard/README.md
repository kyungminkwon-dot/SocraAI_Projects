# Product Dashboard 구축

> 서비스 핵심 지표를 통합 모니터링하기 위한 Databricks 기반 셀프서비스 대시보드

## Overview

기존 Redash 기반 대시보드의 필터·집계 유연성 한계를 해결하기 위해, Databricks Dashboard로 전면 재구축한 프로젝트입니다. 3차에 걸친 리뷰 사이클을 통해 점진적으로 고도화하였으며, 현재까지 실무 부서에서 직접 사용하고 있습니다.

## 문제 정의

| # | 문제 | 상세 |
|---|------|------|
| 1 | 기존 대시보드 한계 | Redash 기반으로 필터·집계 유연성 부족, 지표 정의 불명확 |
| 2 | 모니터링 체계 부재 | DAU, 퍼널, 코호트, 매출 등 핵심 지표를 통합 조회할 환경 없음 |

## 해결 방안

### 1. Databricks Dashboard 기반 전면 재구축

- Global Filter 적용 (구매상품, BM, 구매상태, 신규/기존)
- 파생 필터 컬럼 기반으로 구현하여, 쿼리 파라미터 없이 필터 조합별 즉시 조회 가능
- Mart 레이어에서 GROUP BY CUBE로 사전 집계된 테이블 활용

### 2. 유저 퍼널 체계 설계

6단계 퍼널을 정의하여 유저 행동 흐름을 단계별로 모니터링합니다.

```
가입 → 프로필 생성 → 활동 시작 → 대화 진행 → 대화 완료 → 반복 완료
```

- 각 단계별 전환율 시각화
- 필터 조건에 따른 세그먼트별 퍼널 비교 가능

### 3. 3차 리뷰 사이클을 통한 점진적 고도화

| 버전 | 기간 | 주요 내용 |
|------|------|-----------|
| **V1** | 2025.08 ~ 2025.09 | 핵심 지표 구축 (DAU/WAU/MAU, 유저 퍼널, 코호트 리텐션) |
| **V2** | 2025.09 ~ 2025.10 | 매출/환불 탭 추가, UX 개선, List 지표 9개 추가 |
| **V3** | 2025.11 ~ 2025.12 | 2.0 버전 신규 지표 반영 (GV Lesson, Echo Run) |

각 버전은 실무 부서 리뷰를 거쳐 개선사항을 도출하고 반영하는 방식으로 진행했습니다.

## 대시보드 구성

### 탭 구조

| 탭 | 주요 지표 |
|----|-----------|
| 통합 지표 | DAU/WAU/MAU, 유저 퍼널, 전환율 추이 |
| 대화 | 대화 생성·진행·완료 현황, 대화 완료율 |
| 유저 | 코호트 리텐션, 신규/기존 유저 비교, 유저 세그먼트 분포 |
| 매출/환불 | 매출 추이, 환불율, 구매상품별 매출 비교 |

### 핵심 차트

**유저 퍼널 차트**
- 6단계별 유저 수 및 전환율 시각화
- Global Filter 연동으로 세그먼트별 비교 분석 가능

**구매 코호트별 잔존율**
- 구매 시점 기준 코호트 분류
- 경과 기간별 잔존율 추이를 히트맵으로 시각화
- 유저 이탈 시점 파악 및 리텐션 전략 수립에 활용

## 데이터 파이프라인 의존성

본 대시보드는 dbt 기반 데이터 파이프라인에서 생성된 Mart 테이블을 데이터 소스로 사용합니다.

```
Source → Staging → Intermediate → Core → Mart → Dashboard
```

| 레이어 | 역할 |
|--------|------|
| **Staging** | 원본 1:1 매핑, 컬럼명 표준화, 타입 캐스팅 |
| **Intermediate** | Core 조인 전 사전 연산 (구매/이용권 기간 병합, 유저 세그먼트, 프로필 피벗) |
| **Core** | Fact-Dimension 분리, 통합 이벤트 테이블 (fct_service__event), 유저 Dimension (dim_service__user) |
| **Mart** | GROUP BY CUBE 기반 사전 집계, 업무 목적별 테이블 |
